Quick Guide

  • Landing Page — Control what visitors see on the main page: hero banner, and preview cards for About, Services, and Results with "View More" buttons.
  • Inner Pages — Manage the full content on each standalone page: About, Services, Results, and Contact.
  • Hero Section — Edit the main banner photo, headline text, and statistics.
  • About / Services / Results Previews — Control how many items show on the landing page and button text.
  • Contact Info — Set your address, phone, email, and hours.
  • Social Links — Add your social media profile URLs.
  • Translations — Edit every text in all 3 languages directly.
  • Settings — Change admin password and export/import data.
